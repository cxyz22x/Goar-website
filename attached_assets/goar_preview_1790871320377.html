Chat

The operator loop. Tools, memory, skills, and Computer live in the conversation. Composer is a pill: attach, type, send.

Files & Notes

Browse SSH or the on-device sandbox. Search, upload, zip and rar, a notes editor, a code editor. Git clone lives here.

Computer

Live VNC of a Linux desktop. SSH is only a pipe to 127.0.0.1:5901 unless you open the port. You set port, size, and password in Settings → Computer.

Terminal

Shell on the sandbox or a host you pin. Jobs on SSH keep running if the phone sleeps. The agent does not move onto the VPS.

Browser

One in-app browser the operator and the agent share. You choose search and fetch endpoints.

Creative

Stills, edits, video through providers you enable. Pollinations stills need no key. Video and edits do.
