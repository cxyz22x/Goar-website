Supplied browser demo
Inspection and test results

This HTML is a browser demo, not Goar itself or a browser edition of Goar. Goar's Android marketing, payments and team capabilities are outside this test.

The original uploaded HTML was preserved byte-for-byte. Testing exercised the accessible interface in a browser, without entering credentials, changing providers or relays, clearing sessions, sending marketing messages, making payments or running remote commands.

File inspection

  • 6 inline scripts: all passed JavaScript syntax checks.
  • 205 unique HTML IDs, no duplicate IDs; 65 buttons, 2 forms and 17 inputs.
  • Embedded gzip payload: 4,919,122 bytes; inflated WebAssembly: 20,455,564 bytes, with valid WASM magic and version.
  • The embedded Go/WASM runtime instantiated and reached its ready state in live testing.
  • No separate JavaScript or WASM download is required to boot. Google Fonts is externally loaded.
  • Original file SHA-256: da2dd0ad9acc5a429620e82868ce92ae96ac6076142261485f8dcceba77ff4a0.

Network and storage observations

  • Default Wisp relay: wss://wisp.mercurywork.shop/. Default model endpoint: https://api.free.ai/v1/models.
  • The first inspection logged an uncorrelated 404. Later captured model-list responses were 200; no failing request was captured on the final reload. The 404 is not attributed to the model endpoint.
  • A configuration-write warning was followed by an OPFS gateway save log. Theme persistence passed for a reload, but long-term recovery, backups and encryption were not verified.
  • The visible “Kali connecting…” banner remained during successful chat. Status reported the shared SSH connection failed.
  • Static inspection found support strings for other model providers and localhost Ollama/CDP services. These strings are not evidence that all such services run or were contacted.
  • No static credential preset was found in the inspected shell. This is not a security audit of all compiled WASM behavior.

Coverage boundary

The whole HTML shell and all six inline scripts were inspected or syntax-checked, and the accessible safe journeys above were exercised. This is not exhaustive verification of every branch in the embedded 20 MB compiled runtime. Hidden panels, account-dependent services, remote SSH/VNC, creative generation, MCP execution, destructive session operations and other browser engines remain unverified.

Priority issues: provide a safe History close control; clarify the limited local-shell command set; make SSH connection errors understandable; expose intended demo tools or remove inaccessible claims.

Tested in the development preview. No claim is made about production availability, provider allowances or all-browser compatibility.
