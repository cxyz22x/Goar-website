Android · arm64 · F-Droid posture

One system
on this phone.

Chat, files, terminal, browser, and a live VNC desktop running as a private operator on your device. No account. No telemetry. Bring your own keys and hosts.

Scroll

No Goar server. Everything you type stays on this device unless you send it to a provider or host you chose. API keys, SSH secrets, and memories live on-device — encrypted by the Android Keystore.

No analytics No crash telemetry No update checkers No advertising SDKs Cloud backup disabled

01

Chat

The operator loop. Tools, memory, skills, and Computer live in the conversation. Composer is a pill — attach, type, send. Destinations do not stack.

Operator + tool loop in a single session Memory and skills run on-device MCP servers you configure, not Goar's Composer: attach files, images, audio
02

Files & Notes

Browse SSH or the on-device Alpine sandbox. Search, upload, zip, rar, a notes editor with Markdown, and a code editor. Git clone lives here.

Dual destinations: sandbox + SSH host Full zip / rar / tar support Code editor with syntax highlighting Git clone direct from the Files surface
03

Terminal

Shell on the sandbox or a host you pin. Jobs on SSH keep running if the phone sleeps. The agent does not move onto the VPS.

Persistent SSH sessions across sleep Multiple pinned hosts Agent stays on-device; shell is yours Full PTY — ncurses, htop, vim, tmux
04

Computer

Live VNC of a Linux desktop. SSH is only a pipe to 127.0.0.1:5901 unless you open the port. You set port, resolution, and password in Settings → Computer.

VNC tunnelled over your SSH session Local by default — desktop never exposed Touch-to-click and keyboard passthrough Resolution and color-depth configurable
05

Browser

One in-app browser the operator and the agent share. You choose search and fetch endpoints — Goar does not pick a default provider for you.

Shared between operator and agent tools Search endpoint is yours to set Fetch tool uses the same browser session
06

Creative

Stills, edits, video through providers you enable. Pollinations stills need no key. Video and edits require a key you supply — Goar never holds one.

Stills via Pollinations (no key required) Video generation with your provider key Image edits: restyle, inpaint, upscale Keys stored on-device, never transmitted to Goar
